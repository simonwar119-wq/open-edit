# open-edit：Higgsfield 能力 × 开源技术对标

> 目标硬件：Mac M4 Pro 24GB（本地）+ RunPod 租卡（云）。采集 2026-06-28。
> **一句话结论**：Higgsfield 每项能力都有成熟开源对应物，但没有一个现成 repo = 完整 Higgsfield。可行路线 = **ViMax 当编排大脑 + ComfyUI(Wan2.2 生态) 当本地生成引擎 + 双 LoRA 锁身份(图像 FLUX/视频 Wan)。训练租卡、推理本地。**
> 硬件现实：**M4 Pro 24GB 能跑推理(GGUF 量化)，但所有 LoRA 训练和 14B 级出片必须租 NVIDIA。**

## 1. 身份一致性（对标 Soul ID）= 双 LoRA 栈
Soul ID 本质 = 每人一个 LoRA。"训一次锁全程"的真身是 LoRA，不是 adapter。
- **图像身份** → FLUX.1-dev 上用 **`ostris/ai-toolkit`**(~11k★) 训人物 LoRA（真"训一次"，最高保真）。
- **视频身份** → Wan2.2 上用 **musubi-tuner** 训配套 LoRA，配 **Stand-In**(CVPR2026, WeChatCV/Stand-In, ~1% 参数即插即用挂 Wan2.1/2.2-14B) 免训练兜底。**Phantom**(ByteDance Apache) 多主体一致。
- adapter 全家（PuLID-FLUX 零样本最佳/IP-Adapter FaceID 仅 SD1.5 本地舒适/InstantID/PhotoMaker/ConsisID 原生视频/Arc2Face）只能当**快速预览**，没有"拥有身份"属性。
- **ReActor/inswapper 非商用许可，不能进产品核心。**

## 2. 相机运动控制（对标 DoP）
- **本地主引擎** → **Wan2.1-Fun-1.3B-Control-Camera**（bf16 ~3GB，MPS 能跑，原生 `WanCameraImageToVideo` 节点，带命名 pan/zoom 预设）。
- **快速原型** → AnimateDiff MotionLoRA（唯一一流 Apple Silicon 支持 + 8 个可叠加预设）。
- **真 3D 环绕/升降臂** → ReCamMaster/Uni3C（需租卡）。
- **做 50-100 预设的现实路径**：把相机轨迹**参数化成可复用 Plücker 位姿 JSON**（速度/缓动/幅度/起止位姿/组合），每条存档 = 一个预设，**模型无关、可在任意尺寸模型复用**。这正是 Higgsfield 底层结构，且比"烤进底模"便宜 100x。
- **纯论文跳过**：CameraCtrl II / CamCo / Direct-a-Video。

## 3. 本地视频底模
许可：Wan 系 = **Apache 2.0(商用友好)**；Hunyuan = 腾讯社区许可(**排除 EU/UK/韩**)。
- **最佳 i2v 身份+真实感** → **Wan 2.2 I2V-A14B + 身份 LoRA/Stand-In**（生产核心，云端 A100/H100 出片）> SkyReels-V2 14B > HunyuanVideo-1.5。
- **最 Mac 可行** → **FramePack**(lllyasviel, Apache, ~17k★, 6GB 显存出分钟级 i2v, **有 Mac 原生分支 brandon929/FramePack/MPS** —— 唯一在 M4 Pro 原生跑的一流模型) > HunyuanVideo-1.5 GGUF > Wan2.2 TI2V-5B GGUF。
- **关键事实**：**没有任何裸 i2v 能稳住特定真人脸，运动下都会漂** → 制胜模式 = Wan2.2-14B 底 + 身份 LoRA/Stand-In。
- **Mac 定位 = 原型/过夜批处理盒，非交互**（本地每片分钟级）。
- 新模型留意：MAGI-1.1-24B(Sand AI Apache, SOTA 指令跟随)、SkyReels-V2(无限时长)。

## 4. 开源"Higgsfield 平替"整合项目
- **最佳 fork 基座** → **HKUDS/ViMax**(10.7k★, MIT)：剧本→分镜→**VLM 一致性校验**→并行 i2v。编排+一致性大脑。
- **多模型网关蓝图** → calesthio/OpenMontage(24.9k★, **AGPL**, 14 provider 打分路由)——学模式别抄码。
- **最贴"自有权重/本地优先"** → mainza-ai/milimovideo(Apache, 本地 NLE + IP-Adapter + Story Elements)。
- 中文参考 → HITsz-TMG/VideoClaw(原 FilmAgent, MIT, 首尾帧 i2v)。
- **没有可整体 fork = Higgsfield 的项目**，但不必从 ComfyUI 零件零拼。

## 5. 视频换脸/角色替换
> 换脸=往现有素材贴脸(inswapper 族,逐帧)；身份一致生成=从零生成脸(LoRA/Soul,无逐帧闪烁)。**互补**：生成你控制的镜头用 LoRA，已有真实 footage 用换脸。
- **本地 Mac 最佳** → **FaceFusion**(~29k★, 唯一 CoreML 调优 + 全套修复 GFPGAN/CodeFormer/GPEN + 最佳边缘融合)：换脸→gfpgan_1.4→开遮挡掩码。
- **时序稳定(视频换脸真正难点)**：逐帧→闪烁。2026 新方案 **CanonSwap**(arXiv 2507.02691, 规范空间换脸, SOTA 时序一致) / GaussianSwap。
- **商用红线**：经典换脸栈被 inswapper 非商用许可污染，CodeFormer 也非商用。修复优先 **GFPGAN 1.4(Apache, 商用安全)**。
