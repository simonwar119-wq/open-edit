## 一、最重要的认知纠正：Higgsfield 的护城河不是模型

**它做的事很"轻"，本质是个聪明的编排层 + 预设品味 + 上新速度。** 创始人原话："**intelligence is the moat, infrastructure is a commodity**"。
- **自研**只有：Soul 系列(写实/身份/调色)、DoP(相机)、Mr.Higgs(AI 副导演)。且明确是**后训练/微调/自动选模型/自动写 prompt**，不从零训底模。
- **底模全是接的**：Sora2 / Veo3.1 / Kling3 / Seedance2 / Wan / Nano Banana Pro…
- **~40% 用量走它的高层 workflow（Cinema/Marketing Studio）而非裸模型** —— 这才是它卖的东西。
- 70% 收入来自代理商，客单 ~$1000/年。

**对我们的意义：和它的差距不在"模型不够强"，而在"编排 + 工作流 + 一致性纪律 + 预设库"。这些我们都能自建，而且有它没有的东西（可导出权重、本地省钱、生成即成片）。**

## 二、立刻能用的 3 个结论（直接改善我们昨天的结果）

### 1. 🔴 香槟做不好的真正解法 = "先正常速生成 → 后期补帧慢放"
社区铁律：**别让模型直接出慢动作液体**（必崩成 morphing）。正确做法 = 用正常/慢速生成 → **Topaz Video AI(Apollo 模型) 或补帧做 4x/8x 慢放**。我们昨天让 Seedance 直接出"slow-motion splash"是逆着模型来的。
→ open-edit 应内建一个"liquid slow-mo"管线（正常生成 + 本地补帧慢放），而不是写一句 prompt。

### 2. 防身份漂移 = 3 条强约束（工程化，不靠人记）
- **character sheet 一张图只能一张脸**（多脸是漂移头号诱因，要自动擦掉多余脸）。
- **身份描述块 ⟂ 运动描述块物理分离**，跨镜头**逐字复用**人物描述。
- **一次只改一个变量**。

### 3. prompt 用 MCSLA 公式（<200 词）
**M**odel + **C**amera(命名预设) + **S**ubject + **L**ook(配色/摄影感) + **A**ction(运动)。一个 clip 只放一个主导运镜。真实感词要 `pores / subtle sheen / uneven light falloff`，**禁** `flawless/perfect/8K`。塑料脸的根因常是**模型选错**不是 prompt。
（完整公式/模板/66 个相机预设原文见 `04-可落地工作流与prompt骨架.md`）

## 三、自建路线图（开源栈，符合"本地省钱可复现"）

| Higgsfield 能力 | 我们怎么自建 | 能否本地(M4 Pro) |
|---|---|---|
| Soul ID 锁脸 | **FLUX LoRA(图像) + Wan2.2 LoRA(视频) + Stand-In 兜底** | 训练租卡 / 推理✅ |
| DoP 相机预设 | **相机轨迹参数化成 Plücker JSON 预设库** + Wan-Fun-Camera | 1.3B✅ |
| 视频底模 | **Wan2.2 I2V-A14B**(出片租卡) + **FramePack**(Mac 原生唯一) | FramePack✅ |
| 编排大脑 | **fork HKUDS/ViMax(MIT)** —— 剧本→分镜→VLM 一致性校验→并行 i2v | ✅ |
| 换脸(真素材) | FaceFusion(Mac CoreML) + GFPGAN 修复 | ✅ |
| **我们独有** | 可导出权重 + 时间线/调色/拼接(DaVinci MCP) + 生成即成片 | — |

**关键事实**：没有任何裸 i2v 能稳住真人脸（运动下都漂）→ 制胜模式永远是 **底模 + 身份 LoRA**。这印证了我们"Soul=LoRA"的方向。

**最该绕开**：别去复刻 DoP 那套"RL 烤进自研底模"（最烧钱最不可复现），用"现成 I2V + 相机控制信号 + 预设轨迹"便宜 100x 逼近。

## 五、Higgsfield 的短板 = 我们的机会

1. "Unlimited" 名不副实（唯一无限视频是最差的老模型）。
2. **没有时间线/场景编辑器**，只是 clip 生成器，强制导出 CapCut/DaVinci。← 我们有 DaVinci MCP 底座，能做"生成即成片"。
3. **Credit 焦虑是设计出来的**（生成前不显示成本）。← 我们反着做：成本前置 + 生成台账。
4. 没有电商/广告投放工作流。
