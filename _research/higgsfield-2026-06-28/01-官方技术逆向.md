## 2. 自研 vs Licensed —— 真正的护城河
- **自研**：Soul 系列、DoP、Reasoning Engine/Mr.Higgs。但 Mashrabov 明确：做的是 **post-training/fine-tuning/auto-prompting/auto-selection，不从零训底模**。
- **接入第三方**：Sora 2、Veo 3.1、Kling 3.0、Seedance 2.0、Wan 2.6、Hailuo 02、Flux Kontext、GPT Image 2、Seedream 5.0、Nano Banana Pro。
- **护城河（按重要性）**：① 上新速度+orchestration（新底模几天内包成商用 workflow；**~40% 用量走 Studio 高层 workflow 而非裸模型**）② 预设/viral 数据资产+品味 ③ 代理商分发+高客单。**模型本身是商品，不是主壁垒。**
- 一句话：**"intelligence is the moat, infrastructure is a commodity"（创始人自述）**。

## 3. Soul ID 训练细节 [已证实]
- **≥20 张**多角度多表情照（≥1 全身、忌墨镜/裁脸/强阴影），训练 **3-5 分钟**。
- 官方定位："介于 prompt 和 LoRA 之间，一次训练无限复用"。
- **底层=DreamBooth/LoRA 身份微调**，但**权重锁平台不可导出**（身份"住在平台里"）。MCP 的 `create_character` 只要 1-5 张（轻量参考），训练版才要 20+。
- **我们的天然优势**：FLUX LoRA **权重可导出、本地可复现** —— 正是 Higgsfield 故意放弃的点。

## 4. DoP 相机模型 [已证实+推测]
- **不是 prompt 模板，是真模型**：diffusion + **post-diffusion RL**（受 DeepSeek LLM 推理训练启发），训练去理解 motion/lighting/lensing/空间构图。预设"baked into how the model thinks"。
- 规模：DoP 100+ 预设；Cinema Studio 宣称 1,296 个相机参数。
- **逆向建议**：复刻"烤进底模"代价极高、不可复现 → **改用现成 I2V 底模 + 相机轨迹控制信号(CameraCtrl/MotionCtrl)做预设库，便宜 ~100x**。

## 5. Higgsfield MCP（重点可抄）[已证实]
- 官方 hosted MCP：**`https://mcp.higgsfield.ai/mcp`**（2026/04/30 上线，OAuth 浏览器登录、**无需 API key**、复用平台 credits）。兼容 Claude web/Cowork/Code、OpenClaw、Hermes。
- 核心工具 schema（社区实现 [geopopos/higgsfield_ai_mcp](https://github.com/geopopos/higgsfield_ai_mcp) 与官方对齐）：

| 工具 | 关键参数 | 模型 | 计费 |
|---|---|---|---|
| `generate_image` | prompt, quality(720/1080), character_id, style_id | Soul | 1.5/3cr |
| `generate_video` | image_url(HTTPS), motion_id(req), prompt, quality(lite/turbo/standard) | DoP | 2/6.5/9cr |
| `create_character` | name, image_urls(1-5) | — | 40cr(~$2.5) |
| `get_generation_status` | job_set_id → queued/in_progress/completed/failed/nsfw | — | — |

- **Resources**：`higgsfield://styles`、`higgsfield://motions`、`higgsfield://characters`。
- **可直接抄的 3 点**：① 把 styles/motions/characters 做成 MCP **resources**（agent 列出再选，不死记 ID）② 统一异步 job 模型（单一 `get_status` + 状态枚举含 nsfw）③ OAuth+credits 复用降低接入摩擦。

## 7. 结论：抄哪 3 样 / 绕开哪 1 样
**最该抄的 3 样**：
1. **orchestration/reasoning 层**（自动选模型+自动 prompt+跨镜一致性，40% 用量所在）—— 我们 MCP 把"列资源→选→异步 job→轮询"对齐 Higgsfield。
2. **预设体系且做成可导出资产**（相机运动做成轨迹/控制信号库；viral 风格做成 style/motion 资源）。
3. **Soul ID 的产品形态、但反着做权重**（一次训练跨场景锁脸的 UX 照抄；权重可导出、本地复现 = 我们卖点）。

**最该绕开的 1 样**：**不要复刻 DoP 的"diffusion+post-diffusion RL 烤进自研底模"** —— 最烧钱最慢最不可复现，可用"现成 I2V+相机控制+预设轨迹"极低成本逼近。
